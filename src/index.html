How to use the Space Cyber Garage

A repeatable environment lets the same mission support crew practice, procedure rehearsal and acquisition discussions. Change the question you ask of the run; keep the evidence and decision record connected.

Start with uncertainty. Open a scenario and step through its evidence as the spacecraft operator or cyber defender. Look at source time as well as receipt time. A fresh arrival can carry an old observation.

Make a choice. Seek evidence, hold, or use a configured action when its conditions are met. Enter your rationale. Change crew views to understand what the other team can see, then share a note.

Explain the consequence. Finish the run and open the debrief. Compare another choice from the same configuration. Save a static walkthrough to tell the story without requiring someone to run the simulator.

Scenario Scope And Parameters

This flow demonstration uses synthetic teaching fixtures. Each clock step represents 30 configured seconds; the exercise ends at 180 seconds. The link case has a configured recovery contact at 90–150 seconds. These values explain timing; they are not customer requirements or performance claims. No live spacecraft, government cyber tool, or Proof Labs service is connected.

Role views separate the teaching displays. All data in this synthetic demo is synthetic; switching views is not a security boundary. Notes remain in browser memory until you explicitly save a run or walkthrough. No analytics, accounts, remote assets or automatic network requests are used.
